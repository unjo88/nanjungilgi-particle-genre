## 4. 재현 방법

- **계산 재현**: 공개된 용례 색인과 분석 스크립트로 표4·표5·표6의 수치가 동일하게 재현됩니다.
- **판별 재현**: 위 저본에서 원문을 확보한 뒤, 논문 2장 4)의 공기(연어) 판별 규칙을 적용하면
  색인의 기능 판별(助/代/動) 라벨과 대조·검증할 수 있습니다.
- 계수 절차: 유효 글자 수 산출 → 7자 전수 추출 → 공기 규칙에 따른 기능 판별 →
  100자당 밀도 환산(원계수·보정) → χ²·Cramér's V·500자 창 부트스트랩·Mann–Whitney.
